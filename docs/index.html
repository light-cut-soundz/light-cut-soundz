Trim précis

Découpez votre audio par timestamp en secondes. Opération non-destructive sur le buffer en mémoire.

🔉

Fade in / Fade out

Rampe linéaire sur les N premières ou dernières secondes. Durée configurable au dixième de seconde.

🔊

Normalisation

Normalisation au pic max : tous les samples sont divisés par la valeur absolue maximale pour atteindre 0 dBFS.

⏩

Changement de vitesse

Accélération ou ralentissement par rééchantillonnage (rubato). 0.5× = moitié de durée, pitch monte aussi.

🎛️

Filtres DSP

Filtres biquad IIR : passe-bas, passe-haut, passe-bande. Basé sur le RBJ Audio Cookbook, Q = 0.707.

👂

Aperçu en temps réel

Écoutez l'effet des filtres, fades, vitesse et normalisation pendant la lecture via Web Audio API.

💾

Export multi-formats

Exportez en WAV (natif), MP3, FLAC ou OGG. WAV est disponible partout, les autres via FFmpeg si installé.

🦀

Décodage pur Rust

Lecture audio via symphonia — aucun GStreamer ni codec système requis. Fonctionne sur toutes les distros Linux.

macOS & Linux — Une seule commande

Homebrew sur Mac · .deb ou AppImage sur Linux — détection automatique

curl -fsSL https://raw.githubusercontent.com/light-cut-soundz/light-cut-soundz/main/install.sh | bash
macOS → Homebrew Ubuntu / Debian → .deb Autres Linux → AppImage

ou installer manuellement

macOS

Homebrew · Apple Silicon

Homebrew

brew install --cask light-cut-soundz/tap/light-cut-soundz

Linux

AppImage · deb

Ubuntu, Debian, Fedora, Arch…

Debian / Ubuntu

curl -fsSL -o LightCutSoundz.deb "$(curl -fsSL https://api.github.com/repos/light-cut-soundz/light-cut-soundz/releases/latest | grep -o 'https://[^"]*_amd64\.deb' | head -1)" && sudo apt install ./LightCutSoundz.deb

Autres distributions

mkdir -p ~/.local/bin && curl -fsSL -o ~/.local/bin/lightcutsoundz.AppImage "$(curl -fsSL https://api.github.com/repos/light-cut-soundz/light-cut-soundz/releases/latest | grep -o 'https://[^"]*_amd64\.AppImage' | head -1)" && chmod +x ~/.local/bin/lightcutsoundz.AppImage

macOS & Linux — Une seule commande
